# 运行与兼容

聊天中的文本编辑不依赖额外脚本、API 密钥或指定模型。文件编辑需宿主能够读取和修改用户指定文件；只检查模式不写文件。事实研究不由润色效果替代。

使用完整技能目录，保留 references 和 SOURCES.md。agents/openai.yaml 仅用于 Codex 展示，其他宿主不必读取。通过自然语言点名“中文去 AI 味”即可表达调用意图；Codex 可使用 `$chinese-humanizer`，其他客户端按当前已注册的技能入口调用。

两个技能可以独立使用；组合时先写资讯，再润色，最后核对事实与引用。另一技能未安装时，不承诺调用成功，可按当前技能规范完成本阶段。

支持仓库生成的普通目录 ZIP 和 WorkBuddy 根目录导入包，未逐个完成客户端原生导入与模型端到端验收。技能调用本身不授权发布文章或发送消息。
