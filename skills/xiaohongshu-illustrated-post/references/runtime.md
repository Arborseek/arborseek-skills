# 宿主运行约定

面向 OpenClaw、Codex、Claude Code、Nous Research Hermes Agent、WorkBuddy；格式可加载不等于每个宿主都拥有所需工具。

- 从宿主发现的 SKILL.md 位置解析本技能根目录，scripts/、references/、schemas/ 和 examples/ 都相对此目录；不要假定终端工作目录就是技能目录。
- 使用宿主实际可用、已获准的读写、图片、浏览器和终端工具，不依赖某个厂商的固定工具名。agents/openai.yaml 只提供可选展示信息。
- 脚本选择实际可用的 Python，先确认版本；路径正确引用，中文输出使用 -X utf8。macOS/Linux 常用 python3，Windows 可用已安装的 py -3 或 python。
- 容器或远程执行必须使用其可见路径。输出放用户任务目录，不写技能目录；远程文件需通过宿主支持的附件方式交付，不能假装已保存到用户电脑。
- 不自动安装依赖、字体或浏览器，不改全局配置、不擅自上传私有素材；缺少必要能力时说明缺口与实际完成范围。
- 原生图片生成或浏览器视觉验收不可用时，不用占位图冒充成品，不把静态检查写成视觉验收通过。
- 安装不自动发布内容、部署网站或创建定时任务；这些行动遵循用户当前请求与宿主权限。

## 本技能所需能力

生成计划使用 Python 3.9+ 标准库；中文排字与图片校验另需 Pillow（见 requirements.txt）、本地中文字体与图像生成能力。脚本可用 --font 显式选择有权使用的字体，尤其 Windows 不应依赖 macOS 默认字体路径。缺少图片工具时可独立完成文章、方案和逐页提示词。
