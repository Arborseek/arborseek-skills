# 运行与隐私

标准 SKILL.md 可供 OpenClaw、Codex、Claude Code、Hermes Agent、WorkBuddy、DeepSeek Harness 等具备技能入口的宿主加载；格式兼容不代表每个客户端已实测。核心文件完整独立，不依赖本仓库其他技能。

## 能力检查

- Python 3.9+。提帧/缩略图和标注需要 Pillow；Word 另需 python-docx，见 requirements.txt。FFmpeg 和 ffprobe 为独立外部程序，不能用 pip requirements 假装已安装。
- `python3 scripts/capture.py --help`、`python3 scripts/guide.py --help` 不联网、不写任务文件；Windows 换实际可用解释器。脚本从技能绝对目录定位，素材和结果写到用户任务目录。
- 本地脚本无 API 密钥、无网络请求、无录音转录、无自动 OCR 或自动点击定位。缺依赖时报告准确缺项，先使用已获准的宿主能力，不静默安装或切换云服务。
- 助手读取截图/音频可能使用云模型，本地提帧不等于全程离线。内部录屏交给新服务前明确接收方、数据范围并取得授权；不通过日志、错误消息或外发的溯源文件泄露文件路径与内容。
- 不同模型的图片大小、视频时长和音频限制各异，按当前工具文档处理。没有视频直读也可用本地提帧+可用视觉模型；没有任何视觉能力则停在素材准备，不声称生成了可信教程。

## 数据边界

原视频与原始帧保留在私有工作目录，默认不覆盖、不删除。遮盖在派生图上进行：先实心遮盖，再裁剪/标注，原图不修改。自动检测敏感内容不在本工具范围内，由助手/用户逐图检查账号、手机号、客户资料、密钥、侧栏及通知。遮盖不影响口述中的敏感信息，需要另查文字；不复制完整字幕到对外附件。

交付 public/ 只包含教程和已处理图片；内部 review.md、provenance.json 可能带业务备注，不自动一起打包或上传。默认不包含原视频，因此时间标记可用于回看原件，但不是可直接播放的链接。

SkillHub 上架另需用户授权。名称“录屏转操作教程”，Slug `screen-recording-to-guide`，版本 1.0.0，选择教程/屏幕/文档类图标并在提交后核验；assets/ 中有自制图标。不要把打包成功说成上架成功。
