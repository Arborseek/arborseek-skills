# 提取与视觉核对

先运行帮助确认实际命令。以下命令中的 scripts 路径应替换为已加载技能的绝对路径：

```bash
python3 scripts/capture.py /任务目录/操作.mp4 /任务目录/overview --interval 3 --max-frames 80
python3 scripts/capture.py /任务目录/操作.mp4 /任务目录/detail --times 12.1,12.4,12.8,13.2
python3 scripts/capture.py /任务目录/操作.mp4 /任务目录/segment --start 10 --end 20 --interval 0.5
```

输出目录必须不存在。支持本地普通视频文件，拒绝 URL/播放列表；解码限制为 file/pipe 协议，有超时与最大帧数限制。旋转由 FFmpeg 自动处理，标注使用最终 PNG 的实际尺寸。时间为相对播放起点的请求秒数，不声称记录了准确的点击事件；帧落点可能受视频时间基影响。

`index.json` 包含源哈希/时长、采样区间、请求秒数、帧 ID、尺寸和哈希；`contact-*.jpg` 是带时间点的候选概览。均为内部素材，有可能含敏感信息。帧数超过上限时**显式增大采样间隔并记录**，覆盖指定区间，而不是只截开头。`--times` 超过上限则拒绝；不能把稀疏抽样说成逐帧检查。

先看概览理解结构，再打开选定原尺寸 PNG 看小字和按钮。必须检查开头和结尾，操作前后状态无法衔接时对相应区间加密。不要仅靠全屏像素差判断步骤：鼠标移动可能造成变化，而小勾选框变化可能非常小。工具不自动删除“相同”帧，也不生成步骤结论。

每次提取是独立索引。最终 guide.json 可引用多个索引，分别起别名，例如 overview、detail。先确认多个索引来自同一份录屏哈希，不混用不同版本。

`--audio` 可选导出指定区间的单声道 16 kHz WAV；只供已获准的语音识别工具使用，不自动转录或上传。无音轨时在索引中标明，不生成空音频冒充转录。长录屏先指定区间，避免不必要的大文件。

正常教程按时间顺序整理；跨时间回放、返工取舍要在内部记录原因。截到结果图不等于观察到了点击过程；清楚区分画面证据、口述证据和用户补充。
