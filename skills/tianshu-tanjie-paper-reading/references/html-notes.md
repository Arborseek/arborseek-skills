# 可选图文笔记

只在用户要求网页版、HTML 或图文交付时使用。保留正文分析为主要成果，不为排版增加没有依据的内容。

## 图表

先查看 PDF 对应页面，再按页面坐标裁剪或保留完整页面。图号、图注和内容必须人工式视觉核对；PDF 对象顺序与图注顺序无对应保证。混合栅格/矢量页面不能因为发现一张图片就跳过其他内容。Figure 1 也不一定是架构图。

只选对理解重要的图；保留轴、图例和必要图注，标注明确版本与 PDF 页序。无法可靠定位时展示整页并说明，而非声称“精准裁剪”。没有原图则省略，或明确标注自绘示意及依据。

需要 PDF 渲染时使用当前环境的 PDF 工具/技能和现成依赖；不要默认 `pip install --user`，不要假定系统内置 Python。离线材料不能无授权上传外部转换服务。

## 文件与安全

保存到当前任务 `outputs/` 目录，文件名含 ID 或短标题与版本。优先静态 HTML、内联 CSS、必要图片内嵌/相对路径；不引入 CDN 跟踪或未锁版本的脚本。无数学渲染器时保留可读 LaTeX 文本并说明；用户确需排版公式时优先已有本地渲染能力，外部依赖要说明联网要求，不能再称为完全离线。

对插入 HTML 的所有原始文本做 HTML 转义（包括标题、图注、引用、公式中的 `& < >`）；不要信任论文提供的 HTML 或 JS。链接仅允许经核实的 https/http 来源，拒绝 javascript 等可执行 URL。用户材料不要直接拼入脚本、样式或 shell 命令。

可采用论文卡、方法、证据、局限和后续行动的布局，但只保留任务需要的部分。公式、表格、中文换行和移动端宽度都应预览检查。优先当前应用的文件预览，不默认启动服务。

只有确实需要且用户请求浏览器服务时，绑定 127.0.0.1，仅服务该报告目录，记录本次进程和端口；不要共享全局 PID 文件，不自动杀其他会话的服务。更新报告时在合法 body 容器内修改并维护导航，不把新节追加到闭合的 HTML 文档之后。
