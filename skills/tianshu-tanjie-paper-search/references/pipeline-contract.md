# 四技能串联与独立运行约定

此文件随四个技能各自打包，不要求相邻目录存在。自然语言任务由宿主按已安装技能与当前权限衔接；不是一个脱离宿主自动运行的后台调度器。

## 任意一步都能开始，也能停止

| 入口 | 最少输入 | 本步输出 | 没有其他技能时 |
| --- | --- | --- | --- |
| 检索 | 主题/关键词及筛选条件 | 带版本 ID、摘要、官方链接与范围说明；串联时保存 search-results.json | 独立交付候选，不自动下载 |
| 下载 | 明确 arXiv ID/官方链接，或检索结果中授权选定的 ID | 原始 PDF + 同名 .json（实际版本、哈希、来源） | 自带下载器，不需要检索技能 |
| 解析 | 本地 PDF、官方正文或已有笔记；可带下载元数据 | 阅读说明、结论定位、保存的原图及其索引 | 自带资料目录工具；使用宿主读文/渲染能力，无需下载器 |
| 论文公众号 | PDF、解析资料目录或旧笔记 | 文章 HTML + assets/，以及必要的核验说明 | 自带资料目录、取图和排版工具；直接读所需原文并写作 |

用户只要一步时到这一步结束；明确要求“找、下载、解析再写公众号”时按已给标准继续，不重复索要同一授权。没有安装某个技能不等于任务无法进行，能用现有工具完成就按本步契约交付；缺少正文/工具时说明限制，不自动安装或发布。

## 串联的数据，不是重复生成的文件

检索保存的 `papers[].id` 是选文依据，不是下载许可。下载支持 `--from-search search-results.json` 加显式 ID，核对选择与版本，不默认全选。失败与限流项保留状态，不推进成已下载/已读。

下载 PDF 和元数据保持旧格式兼容。解析或公众号使用本步自带的 `scripts/paper_workspace.py init`，核对哈希后复制入一个新资料目录；不要修改下载原件。可附 `--selection` 保存检索记录，`--selected-id` 核对选择。只有 ID 未指定版本时允许下载器解析明确版本，后续不再自动换最新版。

```text
用户任务目录/某论文-明确版本/
  paper.pdf                 原文副本
  download.json             有下载元数据时保留
  search-results.json       从检索串联且传入时保留
  paper-workspace.json      身份、阅读范围、结论和原图索引
  reading.md                助手保存的阅读笔记
  figures/                  解析时实际使用过的原图
  project-assets/           按需归档的项目网站图片、视频与补充 PDF
  article.json              写作后产生的文章包
  article.html + assets/    写作后产生的网页和图片
```

初始化不会假装完成阅读，不生成分析笔记。助手完成阅读后保存 reading.md，将其相对路径写到 `notes_path`，同步 `paper.read_scope` 与 `claims`；内容和范围必须来自真实阅读。脚本不会从空字段推断科学结论。

## 单篇资料目录 v1

`schema_version` 为 `paper-workspace/1`；`paper` 保留 title、version、source_url、local_pdf、sha256、read_scope。`claims` 沿用公众号交接的 id、claim、status、locator、notes。`figures` 保存实际文件路径、文件哈希、PDF 哈希/版本、PDF 页序、图号、图注、裁剪范围、是否已查看、署名与使用依据。

原图索引只收论文原图；生成图和重绘只加入后续 article.json，不能回写成论文原始资料。reading.md 和 figures/ 不只是聊天附件或临时预览，整篇解析/串联交付时必须留在可复用目录。明确只要不保存的短问答时尊重用户要求，并说明没有形成可复用素材包。

project_assets 是可选数组，旧资料目录仍兼容。解析与公众号各自携带 project_assets.py；相关网站媒体保存后可以继续复用，受限材料记录 link-only/failed 和原因。必须核对项目归属，保存取得时间与来源，不能以绑定某个 paper_version 推断网站素材与该版论文一致。公众号按需选图，不自动将全部网站资料插入文章；视频截图保留父视频哈希和时间戳。

路径相对资料目录；文件夹整体移动后仍能校验。不要只搬 JSON；跨设备需把 PDF、图片和笔记一并移走。来源版本或图片哈希变化时停止复用，恢复对应文件或新建另一个版本目录，不能继续用旧图配新论文。

## 兼容旧材料与缺失状态

- 旧版 Markdown/PDF 直接使用，由助手建立索引，不要求用户手工转 JSON。不强迫重跑检索、下载或全文精读。
- 本地私有论文没有网址时使用实际 PDF 的 SHA-256 URN 与本地版本标识，不能编造官方链接/发表状态。对外发稿前另核查权限与出处。
- 已有完整原图先校验并复用；只有缺图/新增图位才提取。无法定位时保存完整页并标整页，不冒称精准裁剪。
- 已索引图丢失/损坏须明确报告；从对应 PDF 恢复后重新核验，或保存新图 ID，不能用生成图掩盖缺失。
- 没有原文则仅做笔记/摘要级草稿，不承诺全文结论或原图齐备。缺 PDF 渲染器可用宿主现有导出工具配合 import-figure，缺写权限则不能声称图片已保存。
- 文件完整性检查、视觉核对、事实核验、版权/使用核查、平台发布验收是不同状态，不能互相代替。
