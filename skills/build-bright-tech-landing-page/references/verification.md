# 验收与交付

测试范围与改动风险匹配。文字替换不必重建全站测试体系；导航和布局变动需覆盖相关交互与断点。检查实际交付页面，不是技能文案本身。

| 层级 | 检查项 | 通过证据 |
| --- | --- | --- |
| 内容和静态文件 | 真实性、链接目标、资源路径、alt、title/lang/viewport、重复 ID | 位置、输出或命令；未联网链接单列 |
| 当前工程 | 已存在且相关的 lint、测试、构建 | 实际命令、退出码和错误摘要，不改配置使测试假通过 |
| 浏览器布局 | 手机/平板/桌面、长标题、文字放大、裁切、溢出 | 实际视口和截图/观察 |
| 浏览器交互 | Tab/Enter/Escape、焦点、导航、主要行动、减少动画 | 实际操作结果与控制台错误 |
| 上线（仅用户要求） | 目标 URL、资源、路由、环境配置、回滚 | 部署与访问验证，本地截图不能替代 |

默认可检查 360/768/1440px，项目断点或用户设备优先。文字放大到 200% 后检查裁切、遮挡与换行。图片失败保留说明，表单没有后端时不得提示提交成功。

`scripts/check_html.py` 只解析完整静态 HTML 和直接本地引用，不检查 CSS url()、srcset、JS 动态 DOM、字体、外网状态、视觉对比度或后端。框架组件用工程工具检查，再在实际页面验收。

修复本次引入的错误，记录已有问题，不擅自升级无关依赖。一次聚焦一个原因，相同修复无效时换诊断依据，不无限重试。浏览器不可用则交付代码与静态结果，列明未验收视口/交互；新凭据、账户、费用或权限需用户处理。

交付示例（只有执行过才能填“通过”）：

```text
实现：首屏重排与手机导航；现有路由未变。
通过：构建（命令和退出码）；360/768/1440px 无横向溢出；Escape 返回按钮。
失败：无 / 实际问题及影响。
未验证：真实表单后端、线上部署、未访问的外部链接。
交付：文件位置、打开方式和必要的下一步。
```

静态检查 0 退出码不代表整页已通过所有验收；没有浏览器或构建结果时不能声称生产就绪。
