# 运行与兼容

起草不依赖额外脚本、API 密钥或指定模型。研究与事实核查使用宿主现有搜索、浏览和附件读取能力；工具不可用时说明所读材料范围，不宣称完成实时核验。

使用完整技能目录，保留 references 和 SOURCES.md。agents/openai.yaml 仅用于 Codex 展示，其他宿主不必读取。通过自然语言点名“中文资讯写作”即可表达调用意图；Codex 可使用 `$chinese-news-writer`，其他客户端按当前已注册的技能入口调用。

两个技能可以独立使用；组合时先写资讯，再润色，最后核对事实与引用。另一技能未安装时，不承诺调用成功，可按当前技能规范完成本阶段。

支持仓库生成的普通目录 ZIP 和 WorkBuddy 根目录导入包，未逐个完成客户端原生导入与模型端到端验收。技能调用本身不授权发布文章或发送消息。
