# 来源说明

依据员工 HTML 文档转换需求独立编写；不复制在线转换站或第三方技能。示例为自制演示数据，不含私人文档或生产信息。

采用已有 [Pandoc](https://pandoc.org/MANUAL.html) 进行结构转换，[python-docx](https://python-docx.readthedocs.io/en/latest/) 调整文档样式，[LibreOffice PDF 导出](https://help.libreoffice.org/latest/en-US/text/shared/guide/pdf_params.html) 生成文档版 PDF。第三方程序不随技能 ZIP 分发，其许可证由各自项目提供。

不包含网页浏览器、OCR、公式识别、远程采集或云上传；不保证任意 HTML 样式完整保留。
