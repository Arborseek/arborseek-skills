# 保真边界与验收

文档转换保留语义结构，不承诺浏览器样式的像素级复制。默认字体/颜色/间距由文档样式统一；原生表格和文字可编辑，图片只是内嵌，不做 OCR。源样式是要求时先确定用户接受何种差异，不能偷偷换成整页图片。

| 内容 | 自带转换路线 | 验收重点 |
| --- | --- | --- |
| 标题、段落、粗体斜体、列表、引用、代码 | Pandoc 原生结构 | 不漏段、不重复，代码换行，编号起始值 |
| PNG/JPEG/GIF/WebP 静态图片 | 本地/内嵌资源转 PNG 并嵌入 | 图数、顺序、纵横比、透明背景；不复制外部引用 |
| 表格及 rowspan/colspan | Pandoc 表格，再规范边框/宽度 | 合并范围与内容，表头重复，跨页截断、超宽情况 |
| 安全超链接与 #锚点 | Word 原生超链接，PDF 由导出器保留 | XML 关系和实际 PDF 注释，不能只是蓝色文字 |
| 明确内联分页 break-before/page-break-before | 转为 Word 段前分页 | 空白页、图注是否跨页 |
| 全局/外链 CSS、flex/grid、绝对定位 | 默认拒绝未经核对的布局降级 | 隐藏内容、阅读顺序、背景信息、打印范围 |
| JavaScript、canvas、iframe、视频、表单、SVG | 先取得获准静态输出或替代图 | 不执行、不假装转了未呈现的内容；替换须保留含义 |
| MathML、LaTeX、公式脚本 | 自带路线不直接处理，默认阻止 | 按宿主公式工具转为核实的原生公式或清晰公式图，再转换副本 |

脚本移除 script，不执行其内容，但会标记需要静态页面；用户需先取得实际渲染后的内容。style/class 不能用删除标签直接“修好”：有些网页利用 CSS 隐藏机密、切换面板或改变阅读顺序，需检查并明确选取实际应输出内容后再放行。

图片路径中的查询串不用于访问外部，文件定位只用 URL 解码后的路径；原本从远端下载的 HTML 图片应先放到同一资料目录。嵌入 SVG 可能带外部资源，不由本工具自动执行或渲染；已有可信导出图可显式替换。

对于已确认不影响交付的 CSS 降级，可执行 --allow-layout-loss，但报告仍保留差异记录。未知或不支持的标签会阻止转换，以免 Pandoc 悄悄丢弃内容。转换前后计数不代表内容完全相同；关键数字、结论、公式和链接仍需对照原文。

本技能的示例覆盖中文、图、表格合并、外链、目录锚点与分页，属于工具验收；真实客户 HTML 和平台在线导入仍需单独验证。用户已有 HTML 排版稿就是本次转换依据，不另套无关商业报告模板。
