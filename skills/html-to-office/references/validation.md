# 第一版验证记录

2026-09-04，macOS 本地验证。Python 3.12、Pandoc 3.7.0.1、python-docx 1.2.0、Pillow 12.3、LibreOffice Writer 与 Poppler；使用渲染器实际可发现的 Arial Unicode MS 字体。

- 25 项测试覆盖静态内容、动态/公式阻止、CSS 降级门槛、中文编码、内外链、隐藏内容、本地/内嵌图片、路径与符号链接越界、动画拒绝、原生表格与纵横合并、分页、PDF 链接、仅指定格式交付、批量失败隔离和同名输入。
- 自带 office-sample.html 实际生成两页 DOCX 和 PDF。分别渲染全部两页，检查中文无缺字、图片未裁切、表格合并正确、链接有可识别样式、第二节按指定分页；文件结构检查确认原生表格与两条超链接。
- CLI --help 可在无第三方包的环境启动；有些测试环境缺少依赖时会明确跳过，不将跳过记录当作转换成功。

这是模拟静态文档验收，不是任意网页像素级保真、Microsoft Word 原生打开、浏览器动态页面或所有技能宿主的端到端认证。真实文档每次仍须核对资源和全部最终页面。
